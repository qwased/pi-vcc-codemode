## 0. 版本定位

目标是长程任务：**反复压缩后，模型仍知道「做过什么」「要做什么」「要回忆时去哪找」**。0.1.3 由两条互补的线组成：

1. **执行事实**（可确定性观测）：打分、出处、文件语义、截断修正；
2. **模型声明**（固定标记 + 封闭词表）：把算法永远猜不到的东西——意图、副作用性质、预期失败、阻塞——变成可解析的声明，并始终标为 `(declared)`。

两条线的纪律一致：**声明永远不覆盖执行事实**；没有观测时才用声明兜底，且分值更低。

判据：任何改动都要能回答"它减少了哪一次重复调查 / 目标偏离 / 无效 recall"，答不上来就不进本版。

## 3. 实施项

### 3.1 P1 效果感知打分（0.8 天）

**文件**：`src/core/rank.ts`、`src/hooks/before-compact.ts`、`src/codemode/file-ops.ts`

1. 用户块硬保留：先放入最近 16 个 user 块（计入 `usedChars`，超预算按新→旧取舍）。
2. 声明意图 +12（`parseDeclaredIntent`）。
3. **效果分档 +14**，优先级：**执行事实 > 模型声明**
   - 有 nested 记录：变更类（`write/edit/multiedit/apply_patch`，或 nested `bash` 命中变更命令形状 `rm/mv/mkdir/chmod/install`、`git commit|push|reset|checkout|tag|branch`）→ **+14**；
   - 无 nested 记录（实测 7.2%）或参数被丢弃，且 `// effects:` 含 `write|delete|rename` → **+8**，渲染标 `(declared)`；
   - 其余 → 12 分（未知/只读）。
4. 成本修正：变更类块成本 ×0.8 或封顶 120 字符。
5. 不加位置邻接加分；不做"失败"加成（见 §2.2）。

**开工前验证**：Pi 丢弃 nested 参数时是否仍保留 `calls[].name`；否则退回用 Pi 渲染的 `-> a, b, c` 文本，绝不静态扫脚本正文。

**验收**：≥200 块窗口 user 100%、变更类保留率 ≥ 只读、goal ≥ 基线、字符 +≤2%；<73 块小窗口逐字不变；声明与执行冲突时以执行为准且计入冲突计数。

### 3.2 P2 召回可见性（0.7 天）

1. 条件式覆盖 note（`hasCodemodeHistory` 门控）；**同步扩展 `stripRecallNote` 正则**。
2. `summarize.ts:194` 的 `...(N earlier lines omitted)` 追加"不可恢复，请用 `vcc_recall` 查原始条目"。
3. 血缘行：从 `type:"compaction"` 派生一行概况 + `range:[from, to]`；范围两端必须能在当前分支验证，否则只给计数与检索建议。
4. **RECALL_NOTE 增补不可召回范围**：①工具结果正文可召回；②图片、生成时被截断的工具输出、宿主按大小丢弃的 nested 参数不可召回；③历次压缩摘要正文不可召回。

**验收**：连续 3 次压缩声明与血缘行各一次、字符增量不随次数增长；无 codemode 会话逐字不变；无法验证时不输出范围；note 变体均可剥离。

### 3.5 P5 区段出处 + 文件语义修正（0.7 天）

1. `extractGoals` / `formatFileActivity` 返回带 `sourceIndex` 的条目；渲染 `(#41)`；cap 时 `(+N more; #A–#B)`（范围仅在两端可验证时写）。

**陷阱**：`mergeHeaderSection` 的整行 `Set` 去重必须在"去掉行尾 ref"后比较；`touchOnDup` 不用于 Session Goal。

### 3.6 P10 声明族（0.75 天）

**固定标记、封闭词表、任意语言正文；全部渲染为 `(declared)`。**

| 标记 | 位置 | 词表 | 用途 |
|---|---|---|---|
| `// goal: <text>` | 已有 | 自由文本 | 意图 +12 |
| `// effects: <list>` | goal 之后 | `read｜write｜delete｜rename｜verify` | 效果兜底（+8）；`verify` 压制失败语义（P9b 的前置） |
| `// blocked: <text>` | 同一脚本 | 自由文本 | 进 `[Outstanding Context]` 一条 `(declared) … (#N)` |

实现要点：

1. **解析器扫前 3 行注释**（放宽现有 `parseDeclaredIntent` 只看第 1、2 行的限制，`intent.ts:6-19`）；未知 token、非注释位置、超长 → 丢弃并计数（fail-closed）。
2. **`// blocked:` 是多语言 blocker 的替代路径**：不改 `build-sections.ts` 的英文 `BLOCKER_RE`，也不影响任何无 codemode 会话。
3. **guideline 仍控制在 3 条以内**：现有 recall 规则、扩写后的 goal 规则（追加一句 effects 用法）、新增 blocked 规则。措辞用"when"，不用"must"；声明总计每脚本约 +40 字符。
4. **`effects: delete|rename` 同时是 P5b 的输入**（见 §3.7），把"解析 shell"换成"读 token"。
5. **声明与执行冲突**：以执行为准，冲突计入 `details` 与审计（这是 guideline 质量的唯一可测反馈）。

**验收**：无声明时行为与 P1 完全一致；声明含未知 token 被丢弃；`effects: read` 但实际有 write 的脚本按执行记录计分并记一条 mismatch；`blocked` 中文正文可进 `[Outstanding Context]`；guideline 规则数 ≤3。

### 3.7 P5b 删除与重命名（0.2 天，可选）

**输入改为声明优先**：`effects: delete|rename` 提供语义，bash 命令形状（`rm/git rm/git mv`）只作**交叉校验**；两者都没有则不记（fail-closed）。渲染 `Deleted: a.ts (#N)` / `Renamed: a.ts → b.ts (#N)`，合并规则与 Files 相同（最近优先、带 ref）。**不做通配符/变量/重定向的 shell 解析。**

### 3.8 P6 旋钮（0.2 天）

`rankedBriefCeilingTokens`(2000)、`rankedBriefMaxBlocks`(80)、`codemodeSegmentChars`(1500)，默认与现状一致。

### 3.9 P7 度量（0.55 天）

按"变更/只读/未知/user/段尾"分组的保留率；首条指令文本与 `#N` 存续率 vs 压缩次数；Files 段条目数/溢出率/`Created·Deleted·Renamed` 出现率；覆盖声明与血缘行字符增量；嵌套操作形态；**声明覆盖率（goal/effects/blocked 分别统计）与声明-执行冲突率**。

### 3.10 P9 用户消息截断（0.2 天）

## 5. 四条对外不保证

1. 宿主**写入时**丢弃的数据不可恢复：nested 参数、生成时已截断的工具输出、图片像素。
2. 历次压缩摘要的**正文**不可读：只有最近一次在上下文；血缘行只提供"原始窗口可取回"。
3. `#N` 只覆盖 `type:"message"`：custom entries 与 `role:"system"` 不参与。
4. **声明可能缺失、过期或错误**：合规率今天约 19%–55%；`(declared)` 标记只表示"这是模型说的"，不代表事实。

## 6. 发布门（全部确定性）

1. `bun run typecheck` + `bun test` 全绿；Pi 1.0.0 与锁定 1.4.0 双跑。
2. <73 块小会话、无 codemode 会话：摘要逐字不变（列出例外夹具）。
3. ≥200 块合成窗口：user 100%、变更类保留率 ≥ 只读、goal ≥ 基线、字符 +≤2%。
4. 3 次连续压缩：覆盖声明与血缘行各一次；原始指令锚点仍在首位且带 `#N`；同一目标不重复。
5. 效果判定：无 nested 记录 → 声明兜底（+8，标 `(declared)`）；两者都无 → 12 分；不得静态解析脚本正文。
6. 258 字单段中文/英文首消息：Session Goal 非空、带截断指示、条目带出处；10 行需求保留 8 行。
7. 长用户消息首尾完整；短消息逐字不变。
8. RECALL_NOTE 的"不可召回"条目与 §5 逐条一致。
9. 声明：未知 token 丢弃；冲突以执行为准并计数；guideline 规则数 ≤3；`// blocked:` 中文正文可进 `[Outstanding Context]`。
10. 审计脚本可复现 §1 的四条曲线 + 声明覆盖率/冲突率。
